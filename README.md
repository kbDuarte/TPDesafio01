# Catálogo de Filmes

Projeto Android em Kotlin para a disciplina de Desenvolvimento Mobile.

## Integrantes

- Kauan Borges Duarte - 243951
- Camilla dos Santos Fernandes Silvestre - 240249

## Funcionalidades

- Login com credenciais fixas
- Cadastro de filmes
- Cadastro da URL do pôster
- Lista de filmes em cards
- Carregamento de imagem da internet com Glide
- Exclusão de filmes
- Botão Editar presente visualmente

## Credenciais de login

- Usuário: `admin`
- Senha: `1234`

## Como executar

1. Abra a pasta do projeto no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Selecione um emulador ou dispositivo Android.
4. Execute o aplicativo.

## Observação

Os filmes são armazenados em memória durante a execução do aplicativo.
